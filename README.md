# ليالٍ — دردشة الأساطير العربية (نسخة نظيفة)

إعادة بناء كاملة لمشروعك القديم بتقنية React + Firebase، بنفس الفكرة
(تسجيل دخول/زائر، غرف، رتب، رسائل لحظية) لكن بهيكلة نظيفة وقواعد أمان
حقيقية هذه المرة.

## البنية

```
src/
  pages/        Login.jsx · Rooms.jsx · Chat.jsx  (كل صفحة + ملف CSS خاص بها)
  components/   RankBadge, ProtectedRoute
  context/      AuthContext — يقرأ رتبة المستخدم من Firestore مباشرة، لا من localStorage
  services/     firebase.js, authService, roomService, messageService
  constants/    ranks.js — قائمة الرتب والصلاحيات (مصدر واحد للحقيقة في الواجهة)
  styles/       tokens.css (نظام الألوان/الطباعة) + global.css
firestore.rules  قواعد الأمان الفعلية على السيرفر
```

## التشغيل محليًا

1. `npm install`
2. انسخ `.env.example` إلى `.env` واملأه من Firebase Console
   (Project Settings → إعدادات تطبيق الويب — هذا مفتاح عام آمن للنشر، مختلف
   تمامًا عن ملف Admin SDK القديم).
3. أنشئ في Firestore قاعدة بيانات جديدة (وضع Production).
4. فعّل Authentication → طريقتي الدخول: **مجهول (Anonymous)** للزوار،
   و**بريد/كلمة مرور (Email/Password)** للأعضاء.
5. انشر قواعد الأمان: `firebase deploy --only firestore:rules`
   (تحتاج `firebase-tools` مثبتة و`firebase login` أولًا).
6. `npm run dev`

## أهم فرق عن النسخة القديمة (أمان)

- **الرتبة تُقرأ من Firestore مباشرة** (`AuthContext`) لا من `localStorage`،
  فلا يمكن لأحد تزييفها من أدوات المطوّر.
- **`firestore.rules` تفرض الصلاحيات فعليًا**: المستخدم لا يقدر يمنح نفسه
  رتبة إدارية، ولا يرسل رسالة باسم/رتبة شخص آخر، ولا يحذف رسائل غيره إلا
  إذا كان من الإدارة.
- **لا يوجد أي ملف اعتماد Admin أو مفاتيح سرية داخل كود الواجهة** — فقط
  مفتاح الويب العام الذي حمايته تأتي من القواعد لا من إخفائه.
- **لا `innerHTML`** في عرض الرسائل — React يهرّب النصوص تلقائيًا، فينتهي
  خطر XSS من أسماء/رسائل المستخدمين.

## الصور والأيقونات

الصور غير الحساسة من مشروعك القديم (صور الرتب `rank_images/`، الصور
الافتراضية `default-user.png`، `default-visitor.png`، شعار الغرفة) يمكنك
نسخها مباشرة إلى `public/ranks/` و`public/avatars/` بنفس الأسماء
المستخدمة في `src/constants/ranks.js`، بدون أي مشاكل أمنية — هذه ملفات
عادية وليست أسرارًا.

## ما تم بناؤه الآن (المرحلة الأولى)

- تسجيل دخول: زائر / إنشاء حساب / دخول عضو
- قائمة الغرف + إنشاء غرفة
- غرفة دردشة لحظية (رسائل تظهر فورًا لجميع الأعضاء)
- شارة الرتبة بجانب كل رسالة واسم مستخدم
- تصميم بصري متكامل (خط "Aref Ruqaa" للعناوين، لوحة ألوان ليلية/نحاسية،
  فاصل نجمي مستوحى من زخارف المخطوطات)

## المراحل القادمة (لم تُبنَ بعد — نبنيها بالترتيب اللي تحدده)

- الرسائل الخاصة بين الأعضاء
- رفع الصور (يحتاج إعادة ربط حساب Cloudinary جديد)
- البحث عن المستخدمين (يحتاج إعادة ربط حساب Algolia جديد — **ومن سيرفر لا
  من المتصفح هذه المرة**)
- لوحة تحكم لتغيير رتب الأعضاء (تُبنى كصفحة محمية بـ `isStaff()`)
- الإشعارات، أوامر الشات (`/كتم`, `/طرد`, إلخ)
- الملف الشخصي والإعدادات
